# v0.2.6 — Independent AUTO FIT mode

FIT / F is a one-shot command without persistent highlight. AUTO FIT defaults ON and FOLLOW defaults OFF. Both modes use the same pressed-state toolbar styling. Turning AUTO FIT on/off only changes the policy; it does not immediately fit or disturb Follow history. The controls are ordered FIT / AUTO FIT / FOLLOW.

| FOLLOW | AUTO FIT | Enable FOLLOW | Loop START | Export START |
|---|---|---|---|---|
| OFF | OFF | — | Preserve camera | Preserve camera |
| OFF | ON | — | Fit once | Fit once |
| ON | OFF | Preserve camera, capture reference | Preserve camera, reset reference | Preserve camera, reset reference |
| ON | ON | Fit once, capture reference | Fit once, reset reference | Fit once, reset reference |

All loop resets evaluate exact START, optionally Fit, reset the Follow reference, then evaluate/follow the wrapped time remainder. END→START displacement is never applied as ordinary motion. Normal playback, Scrub and Step do not trigger Fit; Follow still applies ground-plane deltas to camera and Orbit target without changing rotation/zoom/relative distance. Subsequent manual navigation remains the new basis for following.

Export samples exact START before optional Fit and always initializes the export Follow reference there. With AUTO FIT OFF its first camera position is exactly the saved Viewer camera position; it does not translate by current-root-to-START displacement. It follows only motion subsequent to START. AUTO FIT ON fits START even with FOLLOW OFF. Export is still frame-based/offline, uses the v0.2.5 projection rules and restores time, playback, position, rotation, zoom, projection, target, FOLLOW, AUTO FIT and Follow internal reference on success, cancellation and failure.

New FBX loading also respects AUTO FIT. OFF means no automatic load Fit; use FIT/F if a replacement file is out of view. Take changes retain their existing behavior: reset the target/reference without a new automatic Fit. Mode values persist during the current Viewer session, not across page reloads.

## Important behavior / acceptance

Preserving camera world position on a loop or Export START cannot also recenter a subject whose root jumps to a different world position. With AUTO FIT OFF, the subject itself may move outside the preserved composition at START. This intentionally follows the requested camera-preservation/reference-reset policy; it does not modify root motion or silently reposition the camera. For a predictable manually composed export, compose at START, then use FOLLOW ON + AUTO FIT OFF.

On real machines, exercise all four combinations with a walking/running clip. With FOLLOW ON + AUTO FIT OFF, set a low or side angle, pan/dolly, scrub and step; verify stable rotation/zoom/distance and normal ground following. Check loop boundaries, first exported frame, cancel/error restoration and FIT/F while both modes are OFF. AUTO FIT ON with FOLLOW OFF should reframe at loop/export START. Also check new-file replacement with AUTO FIT OFF, all export resolutions, Guide/Burn-in and old FBX Takes.

Existing WebCodecs/GPU availability, memory limits, non-Latin font differences, rig-target selection and main-chunk build advisory remain. This environment cannot certify Windows/Linux native execution.
