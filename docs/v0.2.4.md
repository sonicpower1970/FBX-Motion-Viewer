# v0.2.4 — Simplified overlay controls

- BURN-IN is one pressed-state toolbar button, default OFF. The single `burnIn` setting enables/disables both Filename and Frame in preview and MP4 together. The renderer still uses its unchanged filename fitting, basename privacy, frame formatting and resolution-scaled drawing logic. Export locks this setting as before.
- Frame Guide is an original inline SVG showing four frame corners. The button has the tooltip/accessibility name `16:9 Frame Guide`, toggles on click and highlights via `aria-pressed`. The previous text/select control is removed.
- The existing FrameGuide component, ratio catalog and layout utility remain unchanged. The ratio-based state can support additional choices via a future dropdown. Guide rendering remains HTML-only and is excluded from MP4.
- Existing toolbar filename, Timeline counter, camera/Follow/Loop logic, offline encoding and legacy FBX handling are unchanged.

## Acceptance

Guide OFF must not disable Burn-in, and Burn-in OFF must not disable the guide. Check narrow/wide viewport resizing and verify no guide is encoded.

No new runtime dependencies or OS-specific APIs. Existing font/GPU/codec, filename ellipsis, memory and composition-guide limitations remain documented in v0.2.3 and v0.2.2. The existing build advisory for the large main chunk remains.
