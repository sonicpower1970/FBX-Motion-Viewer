## Behavior and limits

Loop START Fit retains the current viewing direction and lens but resets panning/distance offsets to frame the START pose. Manual navigation continues between loop boundaries. A playback update that crosses a boundary evaluates exact START for Fit, then follows from START to the modulo remainder, preserving continuous playback timing. START means animation time zero; displayed start-frame numbering is separate.

Follow ON export deliberately refits START and does not preserve an arbitrary current pan/dolly composition. Follow OFF export retains the current Viewer camera. Export Follow uses explicit per-frame animation evaluation and is independent of playback speed/rAF. End-pose inclusion and MP4 timing are unchanged from v0.2.1.

The 16:9 guide is a composition reference, not a pixel-exact export preview. Fixed vertical FOV with a changed output aspect can show additional image area, especially from a very wide viewport; Follow export also refits START. The guide changes neither camera aspect nor output settings and is never drawn into the WebGL canvas. Current Viewport retains its actual rendered aspect, subject to existing even-pixel rounding for H.264.

Other existing limits remain: browser/GPU H.264 availability, memory-buffered MP4 output capped at 512 MiB, automatic Follow target selection on unusual/multi-character rigs, fixed ground/shadow range and extreme-coordinate precision. No OS-specific Web APIs or external data transfers were added. Windows/Linux/Intel Mac native operation remains a real-machine acceptance item.

## Real-machine acceptance

1. Loop a walking/running FBX several times with FOLLOW ON. Verify one START Fit per wrap, no accumulated drift, and normal navigation between wraps.
2. With matching viewing direction/lens, export from START, middle and near END. Compare camera motion and check subject framing throughout.
3. Export while paused/playing; cancel at the picker and during encode; verify original frame, camera rotation/position/zoom, target and Follow resume.
4. Toggle 16:9 guide, resize portrait/wide, navigate through it and verify it is absent from saved video. Compare 720p/1080p versus Current Viewport.
5. Repeat with FBX 6000 Skeleton and legacy/current Skinned Mesh, multiple Takes, X-Ray, Shadow and long root motion.
